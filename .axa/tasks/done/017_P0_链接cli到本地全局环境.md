使用 npm link将cli目录链接到全局, 使得系统各个目录下可以使用axa-cli

## 实现说明

- 先执行 `pnpm build:packages` 构建 proto/core/cli（tsup 将 `@contagxt/axa-core` 保持 external，链接后通过 `packages/cli/node_modules` 的 workspace 符号链接解析，因此必须先构建）。
- 在 `packages/cli` 目录执行 `npm link`，将 `@contagxt/axa-cli` 链接到全局前缀 `~/.nvm/versions/node/v24.12.0`，`bin/axa` 指向 `dist/index.js`。
- 未修改任何业务代码；npm link 未污染仓库（`git status` 无新增改动，lockfile 不变）。

## 验证证据

- 全局符号链接：
  - `~/.nvm/.../lib/node_modules/@contagxt/axa-cli -> packages/cli`
  - `~/.nvm/.../bin/axa -> ../lib/node_modules/@contagxt/axa-cli/dist/index.js`
- 在 `/tmp`（项目外目录）验证：
  - `which axa` → `/home/wenghaoda/.nvm/versions/node/v24.12.0/bin/axa`
  - `axa --version` → `0.1.0`；`axa --help` 正常列出全部命令
  - `axa list` / `axa show 017` 正常输出（默认项目解析可用）
- 工程校验：`pnpm lint`（biome, 62 files, 0 issues）、`pnpm typecheck`（全部通过）、`pnpm test`（17 passed）、`pnpm build`（含 console 构建成功）。
