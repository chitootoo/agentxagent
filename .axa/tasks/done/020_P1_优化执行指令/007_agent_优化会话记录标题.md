## 术语

建议统一称「会话记录」（conversation entry），而不是「消息」：

- 「消息」偏即时聊天的语义，而任务文件夹里的编号 Markdown 既有用户需求，也有 Agent 的本轮汇总，本质是任务会话的有序记录。
- 「会话记录」能同时覆盖 user / agent 两类条目；文件名后缀就是「会话记录标题」。
- 已把控制台的「立即拉取最新消息」改为「立即拉取最新会话记录」，并在 SKILL.md 与 README 中统一使用该术语。

## 标题生成

- `axa summary` / `axa comment` 新增 `-t, --title <text>`，传入的标题直接作为文件名后缀。
- 未传 `--title` 时的兜底逻辑优化：
  - 跳过「本轮实现」「方案评估」「完成」「summary」等泛化标题，继续找下一条有效内容。
  - 取第一句，最多 40 字，并在逗号、冒号、分号或空格处截断，避免从词中间硬切。
  - 不再把整段原文直接塞进文件名。
- SKILL.md 的完成步骤和规则改为强制使用 `--title` 概括核心改动；控制台复制的执行指令也同步带上 `--title "<一句话核心改动>"`。
- 已把本任务现有会话记录重命名为能一眼看懂的后缀，例如：
  - `003_agent_claim_时签发轮次_agent_id.md`
  - `004_user_每轮重新获取任务详情.md`
  - `005_agent_SKILL_增加每轮重读提示.md`
